# 1.1.1-icon fix (version 1.1.2)

Windows 图标修复版。GitHub Release 标题为 **1.1.1-icon fix**，tag/version 为 **v1.1.2**，以便现有自动更新器识别。Windows x64 免安装包使用 Electron 44.7.2 / Chromium 152.0.7977.149。

## 更新内容

- Windows 图标源 ICO 现在包含 16、24、32、48、64、128 和 256 像素的独立 32 位 PNG 图层。Explorer 和任务栏可选择对应尺寸，避免缩放单一 256 像素图层导致的图标边框或构图异常。
- 其余下载、更新与主题功能沿用 Luna 1.1.1。

## 验证

图标测试检查七个尺寸及 ICO 图像层格式；构建后通过 Windows `ExtractAssociatedIcon` 从 `luna.exe` 提取任务栏图标并确认成功。
