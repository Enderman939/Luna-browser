# Luna Browser 1.2.0

Electron 44.7.2 / Chromium 152.0.7977.149，Windows x64。

## 本次更新

- **登录兼容**：普通页面、扩展会话和网站应用会话统一使用与内置 Chromium 版本匹配的 Chrome User-Agent 及 User-Agent Client Hints。Google Accounts 的 OAuth 弹窗改为真实子窗口，保留 opener、POST 表单和 postMessage 流程。
- **下载自动重试**：连接中断后默认最多重试 3 次、间隔 5 秒。**设置 → 下载** 可关闭重试或调整次数（0–10）与间隔（1、3、5、10、30、60 秒）。暂停、取消、磁盘错误和 HTTP 4xx 不会自动重试；POST 等非 GET 下载不会自动重放。
- **Windows 任务栏图标**：主窗口、OAuth 子窗口、快捷方式和安装器统一使用随应用部署的多尺寸 Luna ICO 与 `luna.browser` AppUserModelID。升级时只修复指向当前安装目录的 Luna 快捷方式，不改动其他程序的快捷方式。
- **标签栏自适应**：标签数量增加时逐步收窄；空间紧张时非活动标签折叠为图标，活动标签仍保留标题，悬停可显示关闭按钮，不再只能横向滚动。
- **动画与个性化**：标签栏、设置页和菜单使用更短的顺滑过渡，并尊重系统“减少动态效果”。个性化页面新增 Luna、Graphite、Mist、Sage、Sand 五套配色预设，可一键套用后继续逐区域微调。
- **产物分离**：浏览器目录与 ZIP 位于 `dist/release/1.2.0`；Windows 安装器位于 `dist/release/1.2.0/installer`，各自拥有独立的 `SHA256SUMS.txt`。

## Google 登录的边界

登录回归只在未输入任何账号或密码的情况下打开 Google 登录页。本次构建环境访问 `accounts.google.com` 超时（`ERR_CONNECTION_TIMED_OUT`），因此无法实测 Google 服务端是否接受登录，也不声称已完成认证验证。浏览器侧已改用匹配 Chromium 版本的 Chrome 身份，并为 Google OAuth 保留真实子窗口；如果 Google 仍按客户端策略拒绝，这属于服务端限制，不能通过隐藏产品标识可靠绕过。
