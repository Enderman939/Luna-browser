# Luna Browser 1.2.2

1.2.3 移除了个性化页面顶部的介绍卡片；请使用 1.2.3。

Electron 45.3.2 / Chromium 156.0.8078.100 / Node.js 24.22.2，Windows x64。

## 修复

- **恢复页面加载**：处理 Electron `loadURL()` Promise 的取消和拒绝。未提交的会话恢复导航因初始化取消时最多重试一次；用户停止、新导航、已提交页面和真实网络错误不会被覆盖，真实失败会显示错误页。
- **网页弹窗**：Electron 提供的 guest WebContents 原样接入 `WebContentsView`；覆盖普通链接、`window.open`、`about:blank` 后续跳转、POST、opener 消息及 `window.close()`。
- **标签页拆分与合并**：从 Luna 窗口外拖出标签会建立新 Luna 窗口；拖入另一同一浏览会话的 Luna 窗口会合并，保持同一 WebContents、页面脚本状态和未保存表单。不能把网页进程直接迁移到 Edge/Chrome。无效拖动和 Escape 取消不会移动标签。
- **无限标签与压缩**：移除固定数量上限，标签和窗口恢复不再截断；标签栏按实际可用宽度为标签、固定页及分组动态分配空间。dense 状态不显示非活动标签关闭按钮，激活后仍可关闭。

- `npm run test:session-restore` 覆盖首次导航取消注入、重试限制、失败页和真实文档加载。
