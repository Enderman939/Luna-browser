# Luna Browser 1.2.1

Windows x64 · Electron **45.2.3** · Chromium **156.0.8078.80** · Node.js **24.22.2**。

## 修复与改进

- Electron 从 44.7.2 升级至 45.2.3，并在 `package.json` 与锁文件中固定版本。浏览器、独立安装器和自动更新 ZIP 使用同一新版运行时。

- 修复启动恢复期间导航被取消后只留下网址、标题仍为“新标签页”的空白状态：等待浏览器就绪和扩展恢复，捕获加载 Promise 的错误。仅对恢复时尚未提交页面的 `ERR_ABORTED` 重试一次；用户停止、新导航和已提交页面不会被自动重试覆盖，其他失败显示可重试错误页。

- 修复网页创建新标签时 Electron `Invalid webContents` 主进程异常：接管 Chromium 传入的原始 WebContents，不创建替代对象；同时覆盖普通新窗口、`about:blank` 后续跳转、POST 新窗口、opener 通信与脚本关闭。
- 取消新建标签、跨窗口接收、分屏和会话恢复的 30 标签限制；保存和恢复不再截断标签或窗口。
- 标签栏按实际可用宽度分配空间，包含固定标签和标签组。数量增加时持续压缩，并保留活动标签、悬停关闭和键盘操作。
- 拖出标签到 Luna 窗口外可拆成新窗口；拖到同一会话的其他 Luna 窗口可合并，并保留同一 WebContents、JavaScript 状态、未保存表单和导航历史。移走最后一个标签后关闭空窗口。
- 普通与无痕会话之间保持隔离；取消拖动和无效拖动标识不会移动标签。

## 本地构建与验证

浏览器目录和 ZIP：`dist/release/1.2.1`。独立安装器：`dist/release/1.2.1/installer`。

`npm run test:tab-window` 覆盖真实网页弹窗、DOM 拖出/合并和 45 标签重启恢复；单元测试额外验证 1000 标签宽度分配和 125 标签、15 窗口的恢复数据。

恢复回归增加了冷启动后的真实 HTML 内容、页面脚本、后台标签和重复网址加载检查，不再只验证保存的网址列表。额外注入首次加载取消，检查能否恢复；网络失败则检查错误状态而非空白页面。

最终验证通过：114 项单元测试，以及 19 项发布验证（实际运行时、16 组功能/UI/安全回归、ZIP/应用归档校验和最终单文件安装器验证）。实际成品 `process.versions` 确认为 Electron 45.2.3、Chromium 156.0.8078.80、Node.js 24.22.2；安装器和安装后的浏览器也验证为 Electron 45.2.3。恢复测试同时确认活动原生网页视图可见、拥有正常尺寸并实际绘制文档像素。源码故障注入覆盖启动取消，打包浏览器覆盖冷启动真实页面恢复。

弹窗、标签、跨窗口状态保留和重启恢复均在 Windows 打包版本验证；实际桌面 IE 与弹窗背景测试使用同版本源码运行。拖动自动化使用 DOM 拖动事件覆盖应用逻辑，尚不等同于各 DPI、多显示器组合下的真人鼠标拖动验收。

安装器未进行数字签名；Google 服务端认证状态未在本次更新中重新验证。

拖出/合并针对 Luna 窗口。Edge/Chrome 的网页进程与 Luna 不共享，不能跨不同浏览器直接迁移同一个标签进程。

修复记录：`artifacts/tab-window-result.json`。成品综合回归：`artifacts/release-1.2.1-validation.json`。

页面恢复记录：`artifacts/session-restore-result.json`；启动取消故障注入记录：`artifacts/session-restore-fault-result.json`。

实际运行时记录：`artifacts/runtime-result.json`。浏览器 ZIP 和安装器各自目录中的 `SHA256SUMS.txt` 提供校验值；GitHub 安装器校验附件命名为 `SHA256SUMS-Luna-Setup-1.2.1.txt`，浏览器自动更新继续使用 `SHA256SUMS.txt`。
