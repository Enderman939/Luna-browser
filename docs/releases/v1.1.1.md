# Luna Browser 1.1.1

本次更新改进下载、完成提醒和文件删除，并加入从 GitHub 正式 Release 自动下载浏览器更新的功能。提供 Windows x64 免安装包，使用 Electron 44.7.2 / Chromium 152.0.7977.149。

## 下载与更新

1. 下载 `luna-1.1.1-win32-x64.zip`。
2. 退出正在运行的 Luna，将整个 ZIP 解压到新的程序目录。
3. 双击 `luna-win32-x64/luna.exe`。已有 `%APPDATA%/luna` 浏览资料会继续使用。

需要 Windows 10 或以上的 x64 系统。运行不需要 Node.js；请保留解压目录里的全部运行文件。附件 `SHA256SUMS.txt` 提供 ZIP 的 SHA-256 校验值。

## 更新内容

- **直接保存下载**：普通下载直接进入设置中的文件夹，未指定时使用系统“下载”目录，同名文件自动编号。移除旧的下载前询问设置，以及没有操作项的“自动保存下载”说明行。
- **明显的完成提醒**：下载完成时，在网页上方显示独立卡片，提供文件名、打开文件、所在文件夹和查看下载入口。显示 12 秒，鼠标停留时暂停消失，不抢输入焦点。下载按钮保留完成数量角标，打开下载面板后清除。
- **前后台与无痕**：后台完成发送系统通知，返回浏览器时补显卡片；无痕完成仅在本窗口提示。完成提醒默认开启，可在“设置 → 下载”关闭。
- **主题一致**：完成卡片和下载角标使用浏览器现有主题；卡片背景、文字、边框、悬停和按钮与下载面板一致。浅色、深色、跟随系统和自定义弹窗颜色实时同步。
- **删除不卡住浏览器**：回收站操作使用独立进程，系统处理较慢时浏览器仍能响应。删除期间显示“正在删除…”并阻止重复操作；失败保留记录，可重试。“删除文件”在列表和确认弹窗中使用红字，保留取消和文件变化校验。
- **GitHub 自动更新**：正式成品默认启动约 10 秒后、此后每 6 小时检查本仓库的最新正式 Release，下载匹配系统和架构的 ZIP，并验证 SHA-256。在“设置 → 关于 luna”可关闭自动下载、手动检查、查看进度、重试，以及确认重启安装。

自动下载不会打断浏览。安装需点击“重启并更新”并确认，多标签页和未完成下载仍会先确认。安装程序在浏览器退出后替换应用，保留旧程序备份；替换或启动失败时恢复旧程序。应用所在目录需可写，浏览资料保留在原用户目录。
