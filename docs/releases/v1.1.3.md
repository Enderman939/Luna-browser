# Luna Browser 1.1.3

Windows x64 本地修复版，使用 Electron 44.7.2 / Chromium 152.0.7977.149。

- Windows 任务栏和标题栏显式加载多尺寸 Luna ICO，避免窗口回退到 Electron 默认图标。
- 覆盖 Windows EXE 的产品名称和文件描述，任务栏菜单显示 Luna Browser，不再显示 Electron。
- 新增 React + Amicro 深色月牙风格的单文件 Windows 安装程序，包含 FadeUp 入场、MorphLoader 加载和 GlowButton 悬停效果，支持减少动态效果设置。
- 安装程序校验浏览器载荷，支持当前用户安装、桌面/开始菜单快捷方式和 Windows 卸载登记；安装期间保持响应，阻止重复安装和中途关闭。自解压启动器采用 Luna 图标和产品名称。
- 支持安装到其他磁盘，升级失败恢复旧程序；拒绝覆盖非空的普通目录，卸载按安装清单删除，保留浏览资料和额外放入目录的个人文件。
- 新标签页紧跟来源标签页插入；关闭当前标签页后返回最近访问过的仍打开标签页。

- 删除已完成下载文件时，用户确认后立即从下载列表移除，回收站操作在独立后台进程执行。
- 浏览器继续响应导航和标签操作，不再等待系统回收站返回。
- 回收成功后移除记录；回收失败会恢复记录并保留文件，用户可以重试。
- 下载任务支持可配置的同时下载数量，超出上限的托管下载和 Chromium 原生下载会排队，暂停、恢复、取消和重启后断点状态会保留。
- 设置 → 隐私与数据提供浏览资料备份与恢复；备份收藏、历史、设置和下载记录，密码默认排除，选择包含密码时使用独立口令加密。
- 设置 → 隐私与数据提供网站权限中心，可集中撤销已保存的摄像头、麦克风、位置、通知和剪贴板读取授权。
- 支持从网站 Manifest 安装独立网站应用窗口；应用使用独立网站存储并默认拒绝敏感权限。
- macOS Apple Silicon CI 在 Pull Request 和手动运行时执行原生构建、签名、打包、成品 smoke 和归档校验。

100 项单元测试通过；最终 Windows 成品通过 12 个打包版 UI、安全和功能集成测试、ZIP 校验，以及安装器实际启动、清理、安装、升级和卸载回归。SHA-256 见 `dist/release/SHA256SUMS.txt`；打包回归记录、安装器记录和界面预览分别位于 `artifacts/release-1.1.3-validation.json`、`artifacts/installer-result.json` 和 `artifacts/luna-setup-preview.png`。

本版本尚未发布到 GitHub Release；本地正式成品位于 `dist/release`。

安装器约 283.88 MiB，包含 React 界面运行时和浏览器载荷；当前 EXE 尚未进行数字签名。
