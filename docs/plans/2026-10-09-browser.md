# Luma Browser Implementation Plan

**Goal:** 在当前空目录建立可运行、可打包的 Windows 中文桌面浏览器。

**Architecture:** Electron 主进程管理独立的 WebContentsView 网页视图和持久化数据。沙盒化的本地渲染器负责浏览器界面，通过窄范围 preload IPC 与主进程交互。网页使用隔离的持久会话，不能访问本地界面的桥接 API。

**Tech Stack:** Electron 44、原生 HTML/CSS/JavaScript、Node.js test runner、Playwright Electron、Electron Packager。

---

### 1. 工程与地址规则
- 新建 package.json、src/core.js、src/store.js、tests/core.test.js。
- 地址栏识别 HTTP(S)、localhost、IPv4 和域名，其余文字通过百度搜索；拒绝执行 javascript/file 等地址。
- 保存收藏、访问历史和上次打开的网页，历史及下载数量设上限。
- 验证：`npm test`，覆盖 URL 判断、危险协议、数据损坏和收藏去重。

### 2. 浏览器主进程
- 新建 src/main.js、src/preload.js。
- 支持标签创建/切换/关闭、前进/后退/刷新、标题与加载状态、收藏、历史、下载、窗口控制和键盘快捷键。
- 独立网页会话禁止 Node，拒绝未经授权的权限请求；只接收可信本地界面的 IPC。
- 页面失败展示本地错误信息，弹窗进入新标签；下载通过系统保存对话框指定目标。

### 3. 中文界面
- 新建 src/ui/index.html、styles.css、app.js、assets/mark.svg。
- 暖白/墨绿视觉系统，标签栏、导航栏、收藏栏、新标签页搜索、常用入口及收藏/历史/下载侧面板。
- 侧面板出现时隐藏原生网页视图，关闭后恢复；尺寸由实际布局测量。
- 支持窄窗口布局、焦点可见性及减少动画系统偏好。

### 4. 验证与交付
- 新建 tests/smoke.js，以本地 HTTP 服务测试网页加载、前后导航、多标签、收藏、历史、失败页面和下载。
- 执行 `npm test`、`npm run test:smoke`、`npm run build`。
- 输出 Windows 可执行目录、start.cmd 与 README.md；保存界面截图供检查。
