# 2.3.1 弹窗保留实时网页背景

问题：原 HTML dialog 绘制在浏览器界面的 WebContents 中，网页是独立原生 WebContentsView。原布局用 overlay/prompts 隐藏网页让弹窗显示，导致弹窗背景空白。

修复：保持当前网页视图可见，在同一浏览器拥有的全尺寸透明 BrowserWindow 中渲染弹窗。网页仍在原 Session 和渲染器运行；分屏保留两侧视图，IE 原生视图在透明层下显示。遮罩拦截鼠标输入，原窗口与网页的键盘输入转向弹窗，原窗口重新获得焦点时将焦点交给弹窗。背景不采用截图或暂停网页。

透明层仅有专用 preload 的 DOM 事件接口。业务状态、网站权限、密码操作和确认队列仍在可信主界面执行。消息按真实源窗口分派，校验显示会话、递增序号、弹窗代次与仍连接的源节点；过期事件忽略并确认最新状态。镜像 DOM 中移除内联事件代码，CSP 禁止联网、表单导航及嵌入页面。原表单值、复选框、选择框、展开项同步，保留光标和滚动位置，中文输入及拖动期间延迟重绘。

父窗口移动、缩放、最小化和关闭同步透明层。最后一个 dialog 关闭销毁透明层，不关闭网页。源 dialog 保留本来的生命周期和事件回调，其绘制透明，避免源与镜像重复绘制。

透明层使用普通 owned window、全窗口遮罩和浏览器输入门控，并通过普通 close 生命周期退出。无痕 DevTools 的关闭回调中原本同步重连 CDP，会在 Electron 44 / Windows 的原生销毁栈中重入并发生退出；重连延后到下一次事件循环，重新检查标签和窗口生命周期后恢复保护。完整无痕回归验证 DevTools 关闭后保护重新附加。

验证：临时用户目录、本机服务器、默认 GPU 下用真实桌面截图检测网页背景像素，并在弹窗打开时改变背景颜色确认真实重绘。实际透明层鼠标与键盘检查权限选择、嵌套收藏输入及保存、取消确认、分屏、无痕授权路由和 IE 显示／点击隔离。原浏览器和成品回归见 artifacts/modal-background-result.json 等。

最终 2.3.1 成品的 modal-background、private-security、essentials、context-menu、features、ie-visibility 均在最后一次打包后通过；无痕 DevTools 恢复也已验证。64 单元测试通过。ZIP CRC、ASAR 一致性、原生运行资源、许可和回归时间通过 verify-package。逻辑大小 322.99 MiB、NTFS LZX 占用 137.70 MiB、ZIP 142.31 MiB。正式启动已确认 luna 窗口与 ProductVersion 2.3.1。
