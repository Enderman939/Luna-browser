# luna 成品存储精简

当前 2.1.1 成品逻辑体积 389,743,939 字节（371.69 MiB）。luna.exe 234.89 MiB，Chromium 语言包 48.30 MiB，应用 ASAR 4.09 MiB。主要占用来自 Electron 运行时。

2.1.2 默认只保留 en-US、zh-CN、zh-TW 的 Chromium 界面资源，剔除应用依赖中的纯开发文件及 pngjs 不使用的浏览器包/覆盖率报告。保留所有引擎、GPU/软件渲染、媒体、IE 和许可证文件；没有删除打印、扩展或开发者工具。

可选 Windows WOF/LZX 压缩让系统透明解压成品文件，降低 NTFS 磁盘分配，不改变程序内容或启动方式。提供 ZIP 降低传输体积；ZIP 解压后的逻辑大小与运行目录相同，文件系统压缩属性不随 ZIP 携带。

精简成品独立生成至 dist/compact/luna-win32-x64，避免覆盖当前正在运行的旧成品。start.cmd 优先选择精简成品。用户目录与现有会话不变。保留所有 Chromium 界面语言可使用 --all-locales。

验证精简和压缩后的实际可执行文件：扩展安装/弹窗/持久化与下载、二维码 PNG/阅读模式/网页工具、默认 GPU 下真实 IE 桌面显示。记录逻辑字节、GetCompressedFileSizeW 分配字节、ZIP 字节和基线。

## 交付结果

- 2.1.2 精简成品逻辑体积 338,572,605 字节（322.89 MiB），比原版少 51,171,334 字节（约 48.80 MiB）。
- Windows LZX 后实际存储字节 144,360,632（137.67 MiB），相对旧包减少约 63.0%。资源管理器“大小”仍是逻辑字节数；文件系统“占用空间”有簇分配取整差异。
- ZIP 149,193,133 字节（142.28 MiB）。ZIP CRC 和必要运行时文件检查通过，ASAR 与实测成品一致，第三方许可证保留。
- 在该压缩成品上，features-smoke（扩展、CRX、MV3、重启恢复、下载及续传）、context-menu-smoke（二维码 PNG、阅读模式、截图、保存/打印等）以及 ie-visibility-smoke（默认 GPU、桌面像素、鼠标输入和窗口生命周期）全部通过。
- 用户旧成品仍在运行，未覆盖其文件或关闭用户窗口；start.cmd 下次启动优先选择精简版。旧目录可在关闭旧程序后删除。
