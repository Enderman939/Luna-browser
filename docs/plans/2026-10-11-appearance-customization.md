# luna 分区域外观自定义

用户要求在设置的外观分类分别调整 UI 背景、设置背景和图标。沿用现有黑白界面，将可配置区域细分为工具栏/收藏栏、标签栏、新标签页、设置/扩展内容、设置侧栏、卡片/输入框、菜单/弹窗、页面工具。区域颜色为空时跟随浅色、深色或系统主题，自定义颜色自动选择易读的文字颜色。

外观页提供实时缩略预览、区域切换、色板与十六进制输入、本地背景图片及强度控制。图标可调整颜色、工具栏尺寸、线条粗细/风格，并独立替换界面按钮或浏览器标识的本地图片。提供单区域、单图标及经内置确认的整体外观恢复。

外观设置保存于现有用户配置，旧配置迁移为默认值。图片经文件选择器授权读取、校验栅格格式和尺寸、重编码为 PNG，保存于专用外观资源目录。配置仅保存经过校验的摘要文件名；内部资源协议只注册于浏览器界面会话，不能指定任意文件路径或加载外部图片链接。

主窗口、菜单、右键浮层和页面工具使用共用主题模型。偏好变更即时同步；工具栏按钮的行为及网站 favicon/扩展图标保持其实际来源。整体外观重置保留主题、主页与其他设置。

验证覆盖区域配色与对比度、图片保存/重启、图标替换/重置、浅色/深色切换、菜单与工具同步、取消恢复、普通网页不能访问图片选择接口或内部资源。安全修复回归应继续通过。
