# Luna Browser 1.0.0

首次公开发行，提供 Windows x64 免安装版。包含当前完成的浏览功能以及弹窗背景实时显示修复。

## 下载与运行

1. 下载 `luna-1.0.0-win32-x64.zip`。
2. 解压整个压缩包，保留全部文件。
3. 双击 `luna-win32-x64/luna.exe`。

运行需要 Windows 10 或以上的 x64 系统，不需要安装 Node.js。`SHA256SUMS.txt` 提供 ZIP 的 SHA-256 校验值。此附件为免安装包。

## 主要功能

- 多标签、多窗口、分屏和标签页组；标签拖动、固定、静音、复制及窗口间移动。
- 收藏文件夹、书签 HTML 导入导出、本地历史与地址栏候选。
- 无痕会话隔离、已知广告和追踪域名拦截，以及逐个扩展的无痕授权。
- Edge / Chrome 扩展安装与管理、网站权限、连接与证书信息。
- 本地加密密码管理、自动填充、随机密码和 CSV 导入。
- 多线程下载、暂停恢复、限速与下载详情。
- 阅读模式、二维码、网页保存、打印、截图和开发者工具。
- Windows IE / Trident 兼容模式、默认浏览器注册、主题与分区域外观自定义。

## 弹窗显示修复

浏览器弹窗打开时，背景网页保持可见并继续更新；遮罩拦截鼠标和键盘，关闭后回到原页面。分屏、无痕和 IE 页面均使用此行为。

## 适用范围

IE 模式依赖 Windows 本机的 IE / Trident 组件；部分扩展、DRM 网站和旧控件的兼容性取决于内核与系统环境。自动更新和跨设备同步尚未接入。详细操作与功能限制见 [README](https://github.com/Enderman939/Luna-browser/blob/v1.0.0/README.md)。
