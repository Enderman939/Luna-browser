# luna 浏览器

一个使用 Electron / Chromium 加载真实网页的桌面浏览器，提供 Windows x64 和 macOS Apple Silicon（M 系列、arm64）版本。中文界面采用黑白配色，主页与新标签页使用居中标识、搜索框和圆形网站入口，支持浅色、深色和跟随系统。

当前公开版本：**1.1.0**，使用 **Electron 44.7.2**。Windows 版支持 Windows 10 及以上的 x64 系统；Mac 版原生运行于 Apple Silicon。

双击 `start.cmd` 运行 `dist/release/luna-win32-x64/luna.exe`。更新后请先关闭当前窗口再启动，确保使用最新文件；本地另有 Beta 成品时，可用 `start.cmd beta` 选择体验版。

### 1.1.0 新增功能

- **导入浏览资料**：新标签页首次提示提供入口，也可在 **设置 → 导入浏览资料** 选择。自动发现当前用户默认位置的 Edge、Chrome、Brave、Vivaldi 和 Firefox 配置；勾选收藏、历史、下载记录和密码后确认导入。收藏保留文件夹，历史最多保留 10000 个网址，下载历史最多保留 1000 条；重复导入跳过已有数据。来源只读，原浏览器数据保留。
- **密码导入**：支持同一 Windows 用户可解密的旧 DPAPI 和 Chromium v10/v11 AES-GCM 密码，导入后重新加密到 Luna 密码库。现代 Edge/Chrome 的应用绑定 v20 密码与 Firefox 的 NSS 密码使用 CSV 路径，导入结果会说明无法直接读取的数量。在来源浏览器的密码管理器中导出 CSV，再点击 **导入密码 CSV**；Luna 不会自动读取或保留明文导出文件。来源正在使用、文件锁定或格式不兼容时，请关闭来源浏览器后重试。
- **下载删除**：每条记录提供 **移除记录**，保留已下载文件；未完成任务先确认取消。已完成记录还可 **删除文件**，显示实际路径并确认后移入 Windows 回收站，同时移除记录。原文件已不存在时可只移除记录。原生 Chromium 下载的结束记录也会保存到下次启动。
- **搜索候选**：输入关键词时依次显示当前搜索、当前引擎的在线建议及本地记录，明确网址优先直达。匹配词加粗，支持方向键、Enter、鼠标和历史／收藏／标签筛选。**设置 → 搜索引擎 → 显示在线搜索建议** 可关闭联网；无痕不请求在线建议、不读取普通历史。在线请求不携带网站 Cookie，超时或网络不可用时保留当前搜索与本地候选。

`npm run test:import-search` 包含合成浏览器配置、真实 Windows 密码加密迁移、重复导入、实际候选列表、过期请求、无痕限制及回收站删除。`npm run build:release` 在 `dist/release` 生成正式版目录和 ZIP。

## 下载

在 [GitHub Releases](https://github.com/Enderman939/Luna-browser/releases/latest) 下载 `luna-1.1.0-win32-x64.zip`，解压整个压缩包后双击 `luna-win32-x64/luna.exe`。请保留同目录的全部运行文件。这个 ZIP 是免安装版，运行时不需要 Node.js。

**M 系列 Mac**：下载 `luna-1.1.0-darwin-arm64.dmg`，打开后把 `luna.app` 拖入 **Applications／应用程序**，再从应用程序启动。也可下载对应 ZIP，解压后移动整个 `luna.app`。两种包均不需要 Node.js 或 Rosetta。

Mac 包采用 ad-hoc 本地签名，尚未通过 Apple Developer ID 签名和公证。首次打开若被 macOS 拦截，请在 **系统设置 → 隐私与安全性 → 仍要打开** 中确认。详细平台差异、构建与验证见 [Apple Silicon 版说明](docs/macos-arm64.md)。Mac 的独立校验文件为 `SHA256SUMS-macos-arm64.txt`。

Release 附有 `SHA256SUMS.txt`。可用 PowerShell 的 `Get-FileHash .\luna-1.1.0-win32-x64.zip -Algorithm SHA256` 校验下载文件。

## 启动

双击工作目录中的 **start.cmd**，启动 **dist/release/luna-win32-x64/luna.exe**；没有正式成品时从源码运行。在终端运行 `start.cmd beta` 可选择本地 Beta，`start.cmd release` 可明确选择正式版。

`dist` 只保留一个正式版和一个 Beta，各自包含可运行目录、对应 ZIP 和 `SHA256SUMS.txt`：

```text
dist/
  release/  正式版，目前为 1.1.0
  beta/     本地体验版（如有）
```

构建按版本号自动选择目录：稳定版本进入 `release`，带预发布标识的版本进入 `beta`。新 ZIP 校验成功后清理同一目录的旧 ZIP；跨类型输出会被拒绝，以防 Beta 覆盖正式版。程序更新前应关闭该目录下运行的浏览器。

打包目录里的其他文件也是运行所需文件，移动程序时请移动整个 `luna-win32-x64` 文件夹。打包版不需要安装 Node.js。

从源码运行（需要 Node.js 22.12 或以上）：

```powershell
npm ci
npm run build:ie
npm start
```

## 功能

- 多标签：创建、切换、关闭、拖动排序、固定、复制和静音；可关闭其他／右侧未固定标签，移动到新窗口或已有同会话窗口，弹窗链接自动进入新标签。
- 多窗口：Ctrl+N 新建窗口，各窗口独立管理标签，普通窗口共享收藏、密码和网站登录状态。
- 无痕浏览：Ctrl+Shift+N 打开隔离会话，默认使用内存存储；自动拦截已知广告和追踪域名，发送 DNT / GPC 隐私偏好，限制第三方 Cookie 与 WebRTC 非代理 UDP。关闭全部无痕窗口后清除网站数据，不记录历史、不保存密码；扩展需逐个明确授权。
- 分屏：两个网页并排浏览，可选择现有标签或新地址、拖动分隔线、切换操作侧、交换左右及退出。
- 标签页组：命名、颜色、折叠／展开、添加／移出标签、解除分组和确认关闭组。
- IE 兼容模式：当前标签使用 Windows 的 IE11 / Trident 内核加载，双向同步网站 Cookie，切换模式时同步同源 localStorage 和 sessionStorage。
- 地址与搜索：域名自动使用 HTTPS，localhost / IPv4 使用 HTTP，其他文本通过所选搜索引擎搜索；输入时显示当前搜索、在线建议与本地标签、收藏和历史候选，可用方向键／Enter 或鼠标选择。
- 网页导航：前进、后退、刷新、停止加载和错误重试。
- 收藏、历史、下载分别拥有独立面板与工具栏按钮，面板中不提供跨功能切换。
- 收藏：地址栏星标、收藏栏与收藏面板；文件夹、名称／网址编辑、移动、拖动排序和通用书签 HTML 导入导出，旧收藏自动迁移，支持最多 5000 条收藏和 1000 个文件夹。
- 新标签页：按网站去重的最近浏览入口，以及可添加、删除的自定义快捷方式；快捷方式和收藏独立保存。
- 历史：按最新访问排列、搜索记录、清除历史。
- 下载：保存对话框、总进度、文件与程序图标、速度、剩余时间、暂停、继续、取消、打开文件和所在文件夹；支持自动保存到指定目录，同名文件自动编号。
- 多线程下载：HTTP Range 分段传输，每段单独显示字节范围、已下载数据与状态；支持限速、断点续传和关闭后恢复未完成的分段任务。
- 标签、收藏与最近网站使用实际 favicon；图标在主进程读取、处理并缓存到本机。
- Chromium 扩展：默认使用 Edge 扩展商店，支持 Edge / Chrome 商店链接或 ID、解压目录、CRX2 / CRX3 / ZIP 安装；支持启停、移除、选项页、工具栏动作和弹窗。
- 网页查找、缩放、上下文右键菜单和窗口控制；支持网页保存、打印、二维码、翻译、阅读模式、截图、网页源码及检查元素。
- 收藏、历史、快捷方式、设置和网站登录状态持久保存。
- 密码管理器：登录提交时询问保存／更新、自动填充、多账号选择、分步登录、密码生成与 Edge / Chrome CSV 导入。

## 设置

通过右上角菜单的 **设置**，或在地址栏输入 `luna://settings` 打开。主页右下角的 **自定义 luna** 直接进入外观设置。

- 搜索引擎：百度、Google、Bing、DuckDuckGo；地址栏和主页搜索共用。
- 外观：浅色、深色、跟随系统；显示或隐藏收藏栏、主页按钮和最近网站入口。
- 外观自定义：分别设置工具栏/收藏栏、标签栏、新标签页、设置/扩展页、设置侧栏、卡片/输入框、菜单/弹窗和页面工具的背景颜色；大面积区域还可使用本地背景图片并调整强度。
- 图标：界面图标颜色、工具栏尺寸、线条粗细/风格；可单独用本地图片替换界面图标或浏览器标识。
- 启动与主页：恢复上次网页或只打开新标签页；主页按钮可以打开自定义网址。
- 下载：选择下载目录、恢复系统下载目录、控制是否询问保存位置、启用分段下载及选择 1 / 2 / 4 / 8 / 16 个分段线程。
- 隐私与数据：清除历史、清除缓存、恢复默认设置；操作前会确认。
- 密码管理器：控制保存和自动填充，搜索、添加、查看／编辑和删除账号，管理不再保存的网站。
- 关于：查看 luna 与 Chromium 版本。
- 网站信息：点击地址栏左侧按钮查看来源、连接及可用的 TLS 证书信息、Cookie 数量，管理摄像头、麦克风、定位、通知和读取剪贴板权限。
- 默认浏览器：在 **启动与主页** 中点击 **设为默认浏览器**，注册正式成品并打开 Windows 默认应用设置，由用户选择 luna。

设置即时生效并自动保存；主页地址需点击保存。

网站信息、权限确认、收藏编辑、删除浏览数据等浏览器弹窗显示在独立透明层中。背景网页保持可见并继续运行；遮罩阻止鼠标和键盘操作穿透，分屏两侧与 IE 页面同样保留显示。关闭弹窗后直接回到原页面，不需要重新加载。

### 基础操作

地址栏输入关键词时，当前搜索在前，随后显示当前引擎的在线建议与本地候选；明确网址优先直达，同一网址优先显示“切换标签”。可按历史、收藏或标签筛选，方向键选中后 Enter 切换或打开。在线建议可在设置中关闭；无痕候选不联网、不读取普通历史。

拖动标签到其他标签前可排序，跨已有窗口拖放可移动；右键标签也可 **移动到新窗口** 或选择已有窗口。Chromium 标签转移正在运行的网页视图，保留未保存输入、页面 JS 和导航记录。普通与无痕窗口之间不能移动。网页加载完成后才能跨窗口移动；IE 标签同步数据后在目标窗口重建原生 IE 视图。固定标签排在前方，不能同时加入标签组；固定和静音状态随会话恢复。批量关闭操作保留固定标签。

收藏面板中的 **管理、导入与导出收藏** 打开完整管理器；收藏栏的文件夹或“更多”也可进入。选择当前文件夹、添加或编辑收藏、拖动调整收藏顺序；编辑时可更改所在文件夹。导入 Edge、Chrome、Firefox 导出的书签 HTML，保留文件夹层级，已有网址不重复导入；导出文件可被其他浏览器导入。导入上限 5 MB、文件夹层级 32 层，仅接受不含嵌入账号密码的 HTTP／HTTPS 链接。删除文件夹会同时删除其子文件夹和收藏，执行前确认。

网站首次请求支持的权限时会显示浏览器内的 **允许／拒绝** 提示；选择会保存在当前会话的网站设置中。支持 HTTPS 和本机测试网站，同源嵌入页面的全部祖先也必须同源；其他来源不继承顶层网站授权。普通窗口保存到本机，无痕授权只存在于本次无痕会话。页面导航或关闭使未完成的授权失效。点击网站信息面板可改为允许、禁止或每次询问，刷新页面后生效。其他尚未提供设备选择或授权界面的权限仍被拒绝。TLS 信息读取自实际网页连接，开发者工具接管调试连接等情况下可能无法提供详情；不会绕过证书验证。

Windows 默认浏览器入口仅在正式成品可用，不修改系统的 UserChoice 默认选择记录。注册的是当前 luna.exe 路径；移动成品后请重新注册。通过外部 HTTP／HTTPS 链接启动时，会将网址交给已运行的 luna 普通窗口；没有运行窗口时先启动。不会把外部链接传入无痕窗口。

在 **设置 → 外观 → 分区域外观** 选择需要调整的区域，用颜色选择器或六位颜色值修改背景；点击“自动”跟随当前主题。文字颜色会自动适配自定义背景，实时缩略预览显示各区域的组合效果。带小圆点的区域表示已自定义。

“选择图片”支持 PNG、JPEG 和 WebP 背景；图标还支持 ICO。图片会复制并处理为浏览器的本地资源，删除原图片后仍可使用，重新启动后保留。背景输入上限 20 MB、图标 4 MB，图片像素与处理后尺寸也有限制。图片不会通过外部链接加载。

图标颜色和线条样式应用于界面绘制的图标，本地替换图片保留自身颜色。浏览器标识可单独替换，并更新窗口图标。网站 favicon 和扩展图标由对应网站及扩展提供。

右上角主菜单采用分组列表：新建、缩放、收藏／历史／下载／扩展／密码、网页操作、设置与帮助、关闭浏览器。缩放行支持减少、增加、恢复 100% 和全屏；菜单保持打开并更新缩放比例。扩展、更多工具及帮助提供左侧子菜单，可用方向键和 Esc 返回。窗口较小时操作列表滚动，关闭入口固定显示。

菜单直接提供新窗口、无痕窗口、标签页组、分屏、密码管理、删除浏览数据、打印、翻译、截图和查找，以及保存网页、阅读模式、二维码、源码和开发者工具。帮助中可查看快捷键和版本。子菜单展开不再改变原生弹窗宽度，鼠标可稳定穿过间隔进入左侧子菜单。

**分屏** 中选择左右网页，然后点击“开始分屏”。点击网页或上方对应标题切换活动侧，地址栏、查找、缩放与网页工具针对该侧。中间分隔线可拖动；聚焦后用左右方向键调整，Home 或双击恢复均分。切换到分屏以外的标签会退出分屏，两个网页标签仍然保留。

**标签页组** 中勾选标签并设置名称和颜色；点击标签栏的组名称折叠／展开，右键组名称编辑。右键单个标签可移到新组、现有组或移出当前组。关闭组前会确认。

无痕窗口之间共享同一次无痕会话，最后一个关闭后再次打开使用新会话。普通窗口的网站 Cookie 和存储不会进入无痕窗口。主动保存的下载文件和收藏会保留；无痕浏览不会隐藏你的网络地址，也不影响网站或网络管理方记录访问。

### 无痕保护与扩展授权

在普通窗口打开 **扩展程序**，每个扩展卡片都有 **允许在无痕中运行** 开关，默认关闭。开启前通过浏览器内弹窗确认：扩展可能读取并向网络发送无痕页面内容，应只允许信任的扩展。扩展声明 `incognito: not_allowed` 时不能授权。无痕窗口只显示获准且已启用的扩展，其网页脚本、后台 Worker、弹窗、Cookie、storage、tabs/windows 接口与普通会话隔离。

首次授权在关闭全部无痕窗口、重新开启后生效，现有纯内存会话不会被迁移到磁盘。已经启用临时扩展存储的会话可以同步授权变化；撤销或停用扩展立即卸载，已执行的网页脚本需要刷新页面才能清除。扩展安装、移除和授权管理在普通窗口进行，无痕菜单里的管理入口会打开普通窗口。无痕不使用扩展的新标签页覆盖。

Electron 不支持在纯内存会话中加载原生扩展。只要为下一次无痕会话授权了已启用的扩展，就使用独立的随机临时目录；没有获准扩展时继续使用内存会话。最后一个无痕窗口关闭时卸载扩展，清除 Cookie、缓存、网站存储并删除临时文件。Chromium 仍占用的文件由随包的 `luna-private-cleanup.exe` 在浏览器进程退出后删除；异常残留在下次启动时再次清理。清理程序只处理该浏览器进程创建的临时目录。

无痕工具栏显示 **已拦截 N**。拦截基于随包的已知广告/追踪域名，按完整域名和子域名匹配；覆盖网页、跨域 iframe 及可附加的 Worker 请求。规则在本机执行，不上传网址，也不持久记录拦截日志。点击保护按钮可暂停当前标签拦截并刷新，再次点击恢复；暂停不会撤销会话隔离、隐私请求头或第三方 Cookie 限制。网站的第一方广告、尚未列入规则的追踪和浏览器指纹可能无法拦截，规则不等同于完整 EasyList 或联网更新的广告插件。

隐私偏好是否被网站遵守由网站决定，WebRTC 限制不等于隐藏所有 IP。第三方 Cookie 限制按内核实际能力启用。打开开发者工具可能接管调试连接，工具栏会显示拦截暂停；关闭开发者工具后重新启用保护并刷新页面。

支持恢复当前区域、恢复单个图标，以及通过浏览器内确认恢复所有自定义外观；整体外观恢复保留当前浅色/深色主题和其他设置。

## 关闭确认与会话恢复

打开多个标签页时，点击关闭按钮或通过系统关闭窗口，会出现浏览器内确认弹窗。

- **取消**：保留所有标签和当前窗口。
- **下次打开时恢复本次全部标签页**：恢复普通窗口、标签顺序、重复网址、内部页面、选中标签、标签页组与分屏布局，不额外插入新标签页。
- 取消勾选后关闭：该窗口不进入下次恢复；其他选择保留的普通窗口仍可恢复。所有窗口都不保留时，下次启动只打开新标签页。
- 无痕窗口不显示恢复选项，不进入会话恢复。

有未完成的下载时也会确认关闭，分段任务会保留进度。关闭、重置设置、扩展授权和移除扩展的确认都使用浏览器内弹窗。

## 删除浏览数据

在 **设置 → 隐私与数据 → 删除浏览数据** 打开，或按 **Ctrl + Shift + Delete**。

时间范围提供最近 15 分钟、1 小时、24 小时、7 天、4 周和全部时间；可勾选历史、Cookie 与网站数据、缓存、下载记录、网站设置和已保存密码，并显示当前统计。

- 历史、Cookie 创建时间、已结束下载记录、网站设置按所选时间过滤。
- 其他网站存储按所选时段访问的网站清理；缓存整体清理。弹窗中明确显示这两类数据的实际清理范围。
- 下载文件、未完成的下载、收藏和扩展安装会保留。
- 未保存的自动填充和托管应用显示无数据，不能勾选。
- 删除过程中显示进度状态；取消或按 Esc 不执行删除。
- 已保存密码默认不勾选，只有明确选择后才会按保存／更新时间删除；普通清理历史和网站数据保留密码库。

## IE 兼容模式

打开普通网页后，在右上角菜单选择 **使用 IE 兼容模式重新加载**。页面会在同一标签内使用系统的 IE / Trident 组件，地址栏出现 **IE** 标记；点击标记或菜单中的 **退出 IE 兼容模式** 返回 Chromium。

- 导航前同步匹配网站域的 Cookie；IE 新增、修改、删除的 Cookie 会回写普通会话，普通会话的 Cookie 变更也会推送至已使用该域的 IE 标签。包含 HttpOnly、Secure、host-only、域、路径、有效期，以及系统 WinINet 支持的 SameSite 标记。同名不同路径的 Cookie 分别处理，退出登录不会因为切换模式恢复旧 Cookie。
- localStorage、sessionStorage 按协议、主机和端口匹配，在进入／退出模式时迁移并重载一次，让依赖网站存储的启动脚本读取新数据。超出 1 MB 的存储不迁移；不迁移分区 Cookie。
- 后退、前进、刷新、停止、地址栏、查找、缩放、打印、保存、可见区域截图和分屏可用。原生 IE 窗口跟随标签、分屏大小与弹窗遮挡，关闭标签或窗口时退出。会话恢复保留标签的 IE 模式。
- 兼容视图使用独立的原生渲染表面，跟随 luna 的网页区域，避免 Chromium 的 GPU 合成遮住 IE。窗口移动、最小化、标签切换和浏览器弹窗会同步显示状态；网络加载失败显示可恢复的错误页。
- IE 模式使用 Windows 的 IE 网站存储，无痕窗口不提供此入口。Chromium 扩展、密码自动填充、Chromium 开发者工具和整页截图在 IE 页面不可用，密码管理库仍可在普通设置页查看。

两个引擎的 IndexedDB、Service Worker、缓存和网页 JS 内存状态不能直接共享。IE 缓存由 Windows 的 IE 组件管理；浏览器中的缓存统计和清理针对 Chromium。页面、TLS 和旧控件的兼容性取决于本机 IE 组件和 Windows 设置，不能保证所有网站或 ActiveX 控件都能运行。

原生宿主为 `luna-ie-host.exe`，随成品一起放在 resources 目录，运行时不需要编译或安装开发工具。源码构建需要 Windows 自带的 .NET Framework 4 编译器。宿主只接收 luna 父进程的管道指令，不向网站暴露 ObjectForScripting 或浏览器管理接口。`compatibility-cookies.json` 仅记录同步过的 Cookie 名称与范围等属性，不保存 Cookie 值；该范围记录用于防止已经删除的 luna Cookie 从旧 IE 存储重新出现，也不会整体清空其他应用的 IE Cookie。

## 密码管理器

工具栏钥匙按钮打开当前网站的密码面板，**管理密码** 或 **设置 → 密码管理器** 打开完整管理页。

- 在可识别的登录或修改密码表单中提交时，询问保存或更新；需要用户点击保存，不会自动提交登录。提示在两分钟后失效。
- 单个匹配账号自动填充；点击账号或密码输入框，显示紧贴输入框的已保存账号下拉卡片，单账号也可查看。卡片包含账号、固定长度密码掩码、关闭按钮和“管理密码”入口；支持方向键选择、Enter 填充、Esc 关闭，输入账号时可过滤列表，填充不会提交登录。工具栏钥匙按钮也可选择账号。
- 下拉卡片优先显示在输入框下方，底部空间不足时向上展开，并适配网页缩放、同源 iframe 和窗口边缘。页面或容器滚动、点击其他位置、切换标签、导航及切换应用时收起，显示时保持网页输入框焦点。
- 支持动态表单、无 form 标签的常见登录组件，以及带 `autocomplete="username"` 的先账号后密码流程。
- 识别 `new-password` 和多密码框，避免将已有密码自动填入新密码或确认密码。网站使用特别的组件、封闭 Shadow DOM 或非标准字段时，可能需要手动填写。
- 可分别关闭保存提示和自动填充；“此网站不再询问”只影响保存提示，可在管理页恢复允许保存。
- 管理页支持网站／账号搜索、手动添加、查看／编辑、确认删除，以及随机生成 20 位密码。查看已保存密码先经过浏览器内确认，密码字段在关闭编辑器或 30 秒无操作后清除；此确认不等同于 Windows Hello 身份认证。
- 使用 **从 Edge / Chrome 导入** 选择这两款浏览器导出的 CSV。导入需要确认，保留已有同网站同账号密码，跳过无效和不安全的网站记录，单文件最多 5 MB、密码库最多 5000 个账号。原 CSV 含明文密码，请妥善处理。

密码库单独保存在用户目录的 `password-vault.json`，整个内容通过 Electron safeStorage 加密；Windows 上使用当前账号的 DPAPI。磁盘文件、浏览器状态和账号列表都不包含明文密码。加密不可用或密码库无法解密时停止保存和读取，保留原文件。

填充按实际协议、主机和端口严格匹配，只允许 HTTPS 或 HTTP 本机测试网站，同源表单 action 与同源 iframe 祖先。跨站 iframe、隐藏字段、浏览器内部页和扩展页不能请求填充。填入网站的密码会成为该网站表单的一部分，应仅在可信网站使用。本版保存于本机，尚未接入云同步、通行密钥或 Windows Hello。

## 下载详情

打开下载面板后，展开文件的 **下载详情** 查看链接、文件大小、已下载量、速度、剩余时间、续传状态和每个分段的进度。展开 **速度限制与完成后选项** 可设置限速（KB/s，0 或空白表示不限）及完成后打开文件或显示所在文件夹。

支持分段且提供文件版本标识的服务器使用并行 Range 请求；响应范围、文件版本和最终长度均会校验。服务器不支持分段时自动采用单连接。POST 响应、blob 和小文件保留 Chromium 原生下载行为。实际并发连接数量受服务器与 Chromium 每个主机的连接限制影响。

分段任务及缓存保存在用户目录，重新启动后以暂停状态恢复，可点击继续。认证下载使用浏览器会话中的 Cookie；链接过期或服务器改变文件时会重新检查，避免合并错误数据。

## 扩展商店

点击工具栏拼图按钮打开扩展菜单，选择 **管理扩展程序** 进入管理页；也可通过浏览器主菜单或 `luna://extensions` 直接打开管理页。

扩展菜单显示实际扩展图标与访问权限信息。点击扩展可打开插件弹窗；图钉控制是否固定到工具栏，固定状态会保存。更多菜单提供选项、启停与移除。顶部总开关控制全部扩展的运行状态，保留各扩展原来的启用配置；刷新网页后应用停用状态。

固定按钮直接使用扩展提供的图标。带 `default_popup` 的扩展打开自己的实际页面；未提供弹窗的扩展执行其点击操作。例如 Dark Mode 点击时切换主题，配置页面通过“更多 → 扩展选项”打开。`chrome` 与 `browser` API 命名空间统一使用兼容桥。

扩展、浏览器主菜单，以及收藏、历史、下载面板使用独立浮层。打开时后面的真实网页保持显示和更新，点击菜单外或按 Esc 可收起。展开与收起使用短暂的淡入缩放动画，按钮与开关提供过渡效果，并尊重系统的减少动画偏好。

标签栏、工具栏、收藏栏与菜单文字不可选中；地址与搜索输入、可复制的链接信息，以及网页正文保留正常选择行为。

- **加载已解压的扩展**：选择含 `manifest.json` 的目录。
- **安装 CRX / ZIP**：选择本地安装包。CRX2 / CRX3 会校验签名，随后显示扩展的权限请求。
- **Edge 扩展商店**：默认入口。详情页右下角提供 **安装到 luna** 按钮；也可在管理页直接粘贴 Edge 商店链接。
- **Chrome 商店**：保留入口。详情页安装按钮与管理页输入共用安装流程。
- 使用裸扩展 ID 时，在输入框左侧选择 Edge 或 Chrome；链接会自动识别对应商店。
- 使用扩展卡片中的开关、移除和选项按钮进行管理；安装后工具栏显示扩展动作按钮。

安装包下载使用浏览器的 Chromium 网络栈和系统代理，完成后校验签名与扩展 ID。管理页显示进度、明确错误和重试按钮。当前网络已实测通过 Edge 下载并加载 AdGuard；Google 安装包 CDN 的可访问性仍取决于网络及代理。

已验证 Manifest V3 的网页脚本、storage、工具栏弹窗、tabs 查询/创建/移除、选项页、启停、CRX 安装和重启恢复。Electron 与扩展桥接实现了部分 Chrome API，依赖尚未实现的 API、Chrome 专用服务或特定运行环境的扩展可能无法完整运行。此支持不等同于完整 Google Chrome 扩展运行环境。

扩展接口在主进程校验实际扩展身份、API 权限及网站范围。读取 Cookie 需要 `cookies` 权限和相应网站权限；标签地址、标题和图标只向具有 `tabs`、匹配网站权限或有效 `activeTab` 授权的扩展提供。临时授权绑定当前标签及来源，在跳转到不同来源后失效。商店页面只开放安装与状态接口。

Windows 分段下载在完成前写入 Internet 区域来源标记，通过下载面板打开旧分段下载时也会补写。无法写入标记时会提示错误并保留可重试状态；目标文件系统需支持来源标记。来源记录不包含网址中的密码、查询令牌或片段。操作系统是否显示警告仍由系统策略、文件类型和声誉判断决定。

本次审计发现与修复说明见 [安全审计报告](docs/security-audit-2026-10-11.md)。

## 网页右键菜单

在网页上点击右键，菜单根据当前内容变化，使用浏览器的浅色/深色主题。菜单支持方向键、Enter、Esc，扩展和“更多工具”提供子菜单。

- **空白区域**：后退、前进、刷新、网页另存为、打印、页面二维码、翻译成简体中文、截图、更多工具、网页源代码与检查元素。
- **选中文字**：复制、指向高亮文字的链接、通过当前搜索引擎搜索、在阅读模式中打开、翻译选中文字。打印所选文字时仅打印选区。
- **链接、图片、音视频**：在新标签页或后台打开链接，复制地址、另存为及复制图片。右键“另存为”始终请求保存位置，即使普通下载已配置为自动保存。
- **输入框**：撤销、重做、剪切、复制、粘贴、粘贴为纯文本和全选；不可执行的项目自动禁用。
- **扩展程序**：显示启用插件通过 `chrome.contextMenus` 注册的实际项目和子菜单，将所选文字、链接和当前标签交给插件。停用扩展后菜单项目移除。

网页另存为提供单文件 MHTML 和完整 HTML（附资源目录）。二维码在本机生成，可复制或保存 PNG。截图默认捕获当前可见的网页区域；**更多工具 → 整页截图** 捕获整页，同样支持复制与 PNG 保存。过大的页面会提示改用可见区域截图。

阅读模式提取正文，并支持调整字号、打印和打开原网页；也可直接阅读所选文字。翻译使用 Google 翻译服务，在新标签页打开，网络可用性由当前连接决定。文字翻译支持单次不超过 5000 字。

源码在新的 `view-source:` 标签页中显示，可恢复上次会话；检查元素打开 Chromium 开发者工具。跨设备同步和 IDM 服务目前尚未接入。

集成检查使用临时用户目录和本地测试服务器，覆盖原有浏览流程、实际 Range 并行请求、Cookie 认证、暂停/恢复、限速、分段缓存、文件字节一致性、原生 POST 下载、文件图标、真实 favicon 和 Chrome MV3 插件的网页脚本、弹窗、tabs API、CRX 安装与持久化。结果和界面截图保存在 `artifacts/`。

打包默认保留简体中文、繁体中文和英文回退语言资源，清除依赖中的类型声明、源码映射和开发报告；网站仍可显示各种语言。需要所有 Chromium 界面语言时可运行 `npm run build -- --all-locales`。保留 Chromium 内核、显卡/软件渲染、视频、打印、开发者工具、IE 宿主和第三方许可文件。

`build:compact`、`build:beta` 和 `build:release` 需要 Windows 10 或以上、NTFS 文件系统。LZX 使用 Windows 的透明文件压缩，直接双击 luna.exe 即可运行，不需要先解压。资源管理器中的“大小”是逻辑字节数，“占用空间”才是压缩后的磁盘用量。ZIP 用于下载或复制；解压或复制到其他目录后，LZX 压缩属性可能不保留，可运行 `npm run package:compact -- <成品目录>` 重新应用。此操作只处理指定成品目录，不处理用户浏览数据或整个磁盘。构建的大小统计保存在 `artifacts/package-size-result.json`。

精简成品逻辑体积约 323 MiB，本机 NTFS 压缩后占用约 138 MiB，ZIP 约 142 MiB；具体大小以 Release 附件为准。精简成品已通过扩展/下载、二维码/阅读/网页工具和默认 GPU 下的真实 IE 显示回归。

项目结构：

```text
src/main.js       窗口、网页视图、标签、下载和 IPC
src/preload.js    本地界面与主进程的桥接
src/core.js       地址解析、设置校验与最近网站去重
src/store.js      收藏和历史的本地存储
src/scoped-ipc.js  按实际窗口所有者分派可信 IPC
src/workspace-model.js 分屏布局和恢复数据校验
src/compatibility.js IE 宿主生命周期、网站 Cookie 与模式切换
src/compatibility-model.js Cookie 范围与网站存储校验
src/native/IeHost.cs Windows Trident 原生网页视图与 WinINet Cookie 桥接
src/downloads.js  Range 下载、校验、限速与恢复
src/extensions.js 扩展安装、会话桥接与管理
src/images.js     favicon 与系统文件图标
src/prompts.js    浏览器内确认请求队列
src/browsing-data.js 数据统计与分类清理
src/context-menu.js 网页右键浮层和动作隔离
src/page-tools.js  保存、打印、二维码、截图和阅读模式
src/extension-security.js 扩展调用者、权限、网站范围及事件数据校验
src/download-origin.js Windows 下载来源标记
src/appearance-assets.js 本地图片处理与界面资源协议
src/ui/           中文界面、样式与交互
tests/            单元与实际浏览流程测试
```

Windows 浏览数据保存在 `%APPDATA%/luna`，macOS 位于 `~/Library/Application Support/luna`。首次升级时会复制同平台旧版 `Luma` 的数据，保留原目录。分段下载记录可跨会话恢复；已结束的 Chromium 原生下载和导入的下载历史也会保存到下次启动。密码库由本机系统账号加密，Windows 与 Mac 密码迁移请使用用户确认的 CSV 导入。

当前版本支持 HTTP / HTTPS 网页与默认浏览器注册，支持摄像头、麦克风、定位、通知和读取剪贴板的网站授权。跨设备同步、联系人／地址自动填充、浏览器自身自动更新及在线恶意网址信誉服务尚未实现。受 DRM 或特定浏览器要求限制的网站可能无法完整使用。
